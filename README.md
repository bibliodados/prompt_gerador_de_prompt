# PROMPT PARA GERAR QUALQUER PROMPT

Ferramenta web simples que permite abrir um **prompt gerador de prompts** diretamente em diferentes plataformas de IA.

O sistema permite:

- Abrir o prompt diretamente no **ChatGPT**
- **Copiar e abrir automaticamente** no **Claude**
- **Copiar e abrir automaticamente** no **DeepSeek**
- Alternar entre **modo claro e modo escuro**
- Copiar, baixar ou editar o prompt
- Usar como **launcher universal de prompts**

# Como usar

1. Abra a página
2. Escolha a IA desejada
3. Clique no botão correspondente

Comportamento do sistema:

| Plataforma | Funcionamento |
|------------|---------------|
| ChatGPT | abre com tentativa de enviar o prompt pela URL |
| Claude | copia o prompt e abre o Claude |
| DeepSeek | copia o prompt e abre o DeepSeek |
