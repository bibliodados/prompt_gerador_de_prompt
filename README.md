# 🧠 Gerador Universal de Prompts

Ferramenta web leve e de alta performance que atua como um **launcher (lançador) universal de prompts**, projetada para otimizar o fluxo de trabalho de *Prompt Engineering* nas principais plataformas de Inteligência Artificial.

## 🚀 Plataformas Suportadas & Comportamento
O sistema permite injetar seu prompt modelo diretamente na interface da IA selecionada:
- **ChatGPT**: Abre em nova guia tentando pré-carregar o prompt diretamente na caixa de entrada via URL.
- **Claude**: Copia automaticamente o prompt para a área de transferência e abre o ambiente, pronto para colar (*Copiar e Abrir*).
- **DeepSeek**: Copia automaticamente o prompt e abre a interface para inserção imediata.

## 🛠️ Recursos e Tecnologias
- Interface Minimalista: Suporte nativo a **Tema Claro e Escuro** com salvamento de preferência via LocalStorage.
- Código 100% Client-Side: Construído puramente com **HTML, CSS e JavaScript (Vanilla)**.
- Único arquivo: Arquitetura **Single-File** sem dependências externas, bibliotecas ou trackers.
- Download direto: Capacidade de exportar e formatar o prompt atual como um arquivo `.txt`.
